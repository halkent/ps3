# Halkent Gaming — PS3 Merkezi

Türkçe PS3 HEN web arayüzü: https://halkent.github.io/ps3/

Standart kurulum, alternatif yöntem ve webMAN seçeneği. Web sayfaları Halkent Gaming için düzenlenmiştir. Lisanslar ve özgün geliştirici kayıtları korunur.

## Kapsam
Web arayüzü Türkçeleştirilmiştir. Derlenmiş PKG/P3T/SELF dosyaları değiştirilmemiştir; Rusça konsol menüleri ve gömülü özgün paket adresleri bu sürümde korunur. Fiziksel PS3 üzerinde test edilmemiştir.
